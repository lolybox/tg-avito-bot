# Быстрое решение проблемы WinError 121 на Windows

## 🔍 Что происходит?
При запуске бота вы видите ошибку:
```
OSError: [WinError 121] Сертификат захвачен
aiohttp.client_exceptions.ClientConnectorError: Cannot connect to host api.telegram.org:443
```

Это проблема **SSL/TLS подключения** из-за антивируса или фаервола.

---

## ⚡ Быстрое решение (2 минуты)

### Шаг 1: Проверьте ваш антивирус

Откройте настройки вашего антивируса и найдите опции SSL/HTTPS сканирования:

#### Если у вас Kaspersky:
```
Настройки → Дополнительно → Антивирусный сканер → 
Отключить "Сканировать защищенные соединения"
```

#### Если у вас ESET NOD32:
```
F5 (Режим продвинутых настроек) → Детализация настроек → 
Поиск по слову "HTTPS" → Отключить "Сканировать зашифрованные файлы и HTTPS"
```

#### Если у вас Dr.Web:
```
Настройки → Настройки антивируса → 
Отключить "Проверять HTTPS-соединения"
```

#### Если у вас Avast/AVG:
```
Меню → Настройки → Общие → Вспомогательные средства → 
Временно отключить "Веб-щит" или "Защищать браузеры"
```

#### Если у вас Bitdefender:
```
Настройки защиты → Web Protection / Anti-phishing → 
Отключить "SSL Scan"
```

### Шаг 2: Перезапустите бот

После изменения настроек перезапустите бот:

```bash
cd tg-avito-bot
python bots/main.py
```

Или просто дважды кликните по файлу `run_bot.bat`

## ❓ Почему это работает только на Windows?

- Windows SSL стек отличается от Unix/Linux
- Антивирусы на Windows активно сканируют трафик через MITM
- На Linux такие антивирусы редки, поэтому проблема встречается реже
